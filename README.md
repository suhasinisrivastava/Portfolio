# Suhasini Srivastava · Portfolio

A 3D model-railway portfolio built with [three.js](https://threejs.org). Drive the train from Vindhyanagar to VIT Vellore to Gurgaon and stop at each station to open that chapter.

It's a single static `index.html` with no build step, so it can be deployed as-is on Vercel, Netlify or GitHub Pages.
